- **Date:** 2026-08-25

- **Scope:** The owner's data-collection master plan (4 new tables + KPIs + Metabase).
  Audit-first delivery: 3 of the 4 proposed tables already existed in better,
  GDPR-grade form but were EMPTY because the `analytics` feature flag was off.
- **Status:** Pipeline live; migration `20260825210000` applied; edge functions
  `analytics-ingest` v7 and `event-operations` v7 deployed.

## Delivered

1. **Pipeline ON**: `analytics` flag enabled/100%. Chain: PrivacyConsentCard opt-in
   (purpose `analytics`) → trackProductEvent → analytics-ingest (allowlists,
   pseudonymized actor, idempotency) → product_analytics_events. Rows appear only for
   members who granted consent — this is by design, not a bug.
2. **KPI RPC** `admin_engagement_stats(p_days)`: funnel (new members / first join /
   median days signup→first join / returning-with-2+-events-in-30d = North Star),
   piggyback (external_event_social_intents), hub stages, per-event analytics counts,
   feedback quality (k-anon ≥3), scraper source health. health.view-gated.
   Rendered as the "Kapcsolódási tölcsér" card at the top of Admin → Outcome.
3. **Soul metric**: post_event_feedback + mood_score/met_new_people/want_to_meet_again;
   PostEventFeedbackCard gained an emoji mood scale + 2 questions; event-operations v7
   validates and saves them.
4. **New analytics events**: `external_social_intent` (piggyback click; the numerator
   of the Piggyback Rate KPI) and `explore_search` (bucketed count only — the search
   text NEVER leaves the client, by allowlist design). Explore favorites reuse
   `interest_selected` with surface=explore.
5. **Source health**: scraper_runs.http_status; worker passes the listing HTTP status
   (generic.mjs returns {events, httpStatus}; log_scraper_run has p_http_status).

## KPI → data mapping (the owner's II. section)

- **Piggyback Rate** = external_social_intent events (or intents_active) /
  event_detail events with external surface. Both in the KPI RPC / analytics table.
- **First-Meet Success** = funnel.median_days_to_first_join (target < 14 days).
- **Hub conversion** = hubs{} stage counts once virtual-hub activation flows.
- **Retention North Star** = funnel.returning_members_30d.
