# AI/Dev Prompt — v1.15.0 (Playwright event-scraper worker)

- **Date:** 2026-08-25
- **Version:** 1.15.0
- **Scope:** Reuse the operator's searchforge/Playwright browser-automation approach to
  render JS-heavy Hungarian event sites offline and feed real dated events into Hobbeast,
  without touching the no-JS Edge pipeline.
- **Status:** Working prototype LIVE — 20 real jegy.hu concerts ingested and served
  publicly under "Külső programok". Scheduled 3×/day on GitHub Actions.

## Why

v1.14.0 established the seeded feed sources are JS-rendered; the SSRF-hardened no-JS Edge
fetcher publishes nothing from them. Source E:\Work\Smartsearchtool\searchforge-repo is a
Playwright + stealth crawler (robots/SSRF/dedup/scheduler) the operator built. This
release reuses that *approach* as a separate offline worker.

## Delivered

1. `scraper-worker/` (Node + Playwright, ESM). `index.mjs` orchestrates; `src/fetch.mjs`
   (robots gate + HTTPS static fetch); `src/sources/jegyhu.mjs` (render listing → collect
   detail URLs → static-fetch detail → parse `*Event`/`MusicEventMarkup` JSON-LD →
   normalized event objects); `src/ingest.mjs` (POST the service-role RPC).
2. Migration `20260825140000_scraped_external_event_ingest`:
   `ingest_scraped_external_events(jsonb)` (service_role only; future-date + title gate;
   idempotent upsert on (external_source, external_id)) + extended external_source CHECK
   to allow a dedicated `scraper` bucket.
3. `.github/workflows/event-scraper.yml` — cron `17 4,12,20 * * *` (3×/day Budapest) +
   workflow_dispatch. Repo secrets set: SUPABASE_URL, SUPABASE_SERVICE_ROLE_KEY.

## Continuation instruction

1. Add sources as `src/sources/<name>.mjs` returning the normalized event shape (see
   README) and register in `SOURCES` (index.mjs). Good next targets: welovebudapest
   (`/programok/` has 128 event links), venue ICS/JSON-LD detail pages, more jegy.hu
   categories (theatre/family/festival). No schema change needed.
2. Politeness: keep detail fetches sequential w/ delay; honor robots; only future-dated
   titled events ingest. Watch GitHub Actions minutes (public repo = free/unlimited).
3. Optional: reuse more of searchforge (proxy-pool, domain-rate, dedup-policy) for scale.
4. Rotation/secret hygiene: the scraper uses the service-role key via GitHub secret only;
   never commit it. The ingest RPC is the only write path.

## Rollback

Disable the GitHub Actions workflow (or delete it). Scraper rows are
`external_source='scraper'`; to hide them set is_active=false or import_state<>'active'
via a service-role update. The RPC + constraint change are additive; a forward migration
can drop them if ever needed. No Edge-pipeline or frontend change to revert.
