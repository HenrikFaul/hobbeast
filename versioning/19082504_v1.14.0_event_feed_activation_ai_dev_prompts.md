## Key gotcha for the next agent

- You CANNOT forge a `sync_due` from outside: the nonce must be pre-issued by
  `dispatch_external_event_feed_due()` into `external_event_feed_cron_dispatches` and is
  consumed once. The dispatcher signs `hmac(issued_at || '.' || jsonb_body::text, secret)`
  where `jsonb::text` has `": "`/`", "` spacing — match that exactly if reproducing.
  To trigger a run, call `dispatch_external_event_feed_due()` as service_role.

## Why no events yet (audit of ~18 endpoints)

Seed V4 sources are JS-rendered listings / articles. None expose static RSS/Atom/ICS or
server-side Event JSON-LD with dates. tixa.hu embeds 64 events in Next.js `__NEXT_DATA__`;
jegy.hu category = `BreadcrumbList` only. The no-JS, no-arbitrary-selector, SSRF-hardened
fetcher correctly publishes nothing from these. Pipeline is correct; source data is the gap.

## Rollback

Vault/Edge secrets can be rotated/unset. No schema or app-code change to revert.
