## Objective

Turn the current 1.7.6 codebase into a provable baseline on which the next 14 prompts can
build safely. This release ships additive docs, a secret-leak fix, and a typecheck script/CI
wiring change. It deliberately does **not** add features, DB migrations, or dependency bumps.

## Deliverables

1. **Secret leak fix** — `src/integrations/supabase/client.ts` wrong-project log no longer
   prints the full Supabase URL; only the project ref (public) and expected ref.
2. **Production readiness baseline** — `docs/PRODUCTION_READINESS_BASELINE.md` with explicit
   PASS / PARTIAL / BLOCKED per surface and cited evidence.
3. **Production risk register** — `docs/PRODUCTION_RISK_REGISTER.md` with severity-ordered
   P0–P3 risks, owner, mitigation, gate, rollback plan.
4. **Historical secret exposure register** — `docs/HISTORICAL_SECRET_EXPOSURE.md`
   (provider names + rotation status only; no key values). Scan evidence: 0 credential hits
   in tracked source + BASEREQUIREMENTS text files, positive control check.
5. **Edge Function test harness foundation** — `docs/TESTING.md` §3 with required fixtures
   and the extract-pure-logic pattern; explicitly marked BLOCKED until a Deno runner is wired.
6. **`typecheck` script + CI consistency** — `package.json` gains `typecheck`; CI now
   runs `bun run typecheck`.
