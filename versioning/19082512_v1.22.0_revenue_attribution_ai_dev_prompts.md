# AI/Dev Prompt — v1.22.0 (Revenue attribution layer)

- **Date:** 2026-08-25
- **Version:** 1.22.0
- **Request:** "tedd az alkalmazast sokkal ertekesebbe" — detailed plan + build it
  without regressions.
- **Status:** Phase 1 delivered and verified on live data.

## The gap this closes

354 sources, 1061 live programs with ticket links and prices — and zero evidence
that anyone clicks through. Pillar 1 of the monetization plan (5-8% marketplace
commission) cannot be invoiced on traffic nobody measures, and a venue cannot be
sold a partnership without showing what it receives.

## Delivered (phase 1)

1. `outbound_clicks` table (migration 20260826050000) + `track_outbound_click`
   RPC. Client sends only the event id + surface; source_id, price and target URL
   are read server-side so attribution and ticket value cannot be forged.
   30-second same-user/same-event de-duplication.
2. Tracking wired into both outbound CTAs (EventDiscoveryCard, EventDetail),
   fire-and-forget and exception-contained — a measurement failure must never
   block the member from reaching the partner (regression test covers a
   synchronously throwing RPC; the test caught this before release).
3. `admin_partner_performance(p_days)` RPC + "Partnerek" admin tab: per partner
   live programs / clicks / distinct members / ticket value / 5-8% commission
   range, plus top-clicked programs and a daily series.
4. Commission is labelled POTENTIAL in SQL comments and in a UI footnote — it is
   a click-time price estimate, not a booked sale.

## Continuation (phases 2-3, not built)

- **Partner portal**: venue login showing its own performance — the B2B SaaS
  entry product. Phase 1 supplies its data.
- **Boost / promoted placement**: `promoted_experiences` exists but is not wired
  to a sales flow; phase 1 click data gives the pricing basis, so this follows
  the portal.

## Honest scope note

A specific valuation increase cannot be responsibly guaranteed — company value
follows actual revenue, growth and market multiples. What this delivers is the
missing *revenue capability*: without it every monetization pillar is blocked and
an appraisal prices the platform as a content aggregator rather than a
marketplace.

Partners tab entry and the two onClick handlers. No existing logic was modified.
