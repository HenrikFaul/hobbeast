## Product and design decisions

### Community mark

Two alternatives were considered:

1. an abstract node/constellation symbol, which communicates networks but becomes generic and
   unclear at the compact header size;
2. a direct group mark with three people, a shared baseline and one connecting arc.

The second option was chosen because the group reads immediately at roughly 40 pixels and keeps
the established Hobbeast color language. The wordmark, accessible home-link label and component
dimensions remain stable.

### Sharing-first language

The canonical Explore message is **“Amit szeretsz, hozd közénk.”** It invites both contribution
and curiosity. Previous strong copy was not deleted: the marketing registry keeps approved older
variants as `eligible`, while tests ensure only the canonical variant renders in the current
surface. This same preservation rule applies to **“A hétvégéd nem egy feed. Menj, és éld meg.”**
and **“Nyerjük vissza egymást.”**

### Random placement

Arbitrary injection anywhere in the page was rejected because it could interrupt forms, reorder
navigation or cause cumulative layout shift. The chosen design uses multiple pre-approved slots
on Home, About and Explore, selects one eligible slot with equal probability per session, and
keeps that choice stable for the session.

Persistent random-key gap lookup was also rejected because unequal gaps create permanent
selection bias. The database now orders the bounded eligible corpus, gives each row an equal-width
interval and maps the random cursor to one ordinal. Each eligible claim therefore has exactly
`1/N` probability.

### Localized research domain

- `community_research_claims` stores stable source identity, original locale, year, URL/DOI,
  original-statement SHA-256, claim-level review/publication lifecycle, active state, safe
  placements and audit metadata.
- `community_research_claim_translations` stores each locale's statement and attribution plus
  its own SHA-256, review state, publication state, translator note and reviewer evidence.
- Editing any display field recalculates the hash and automatically returns the locale to
  `pending_review` / `draft`.
- An active claim must have an approved, published, hash-matching original translation. A
  requested locale can display only when independently approved, published and hash-valid;
  otherwise the RPC falls back safely.
- Stable topic keys and optional topic-label translations support search/localization without
  translating machine identifiers.

### Seed and editorial safety

- The seed inserts the 30 approved Hungarian records, 22 topic keys and 96 exact relationships.
- Every seed write uses `ON CONFLICT DO NOTHING`. Re-execution cannot overwrite an editor's
  decision, replace a later translation or reactivate a withdrawn claim.
- The original workbook and Markdown remain unchanged.
- Generated deliverables:
  - `outputs/20260825-community-research/Hobbeast_kozossegi_allitasok_elfogadott_v1.12.0.xlsx`
  - `outputs/20260825-community-research/Hobbeast_kozossegi_allitasok_emberi_felulvizsgalat_v1.12.0.xlsx`
- Both workbooks include reconciliation/audit material; the accepted workbook also documents the
  actual localization, review, hash, topic, save and RPC model.

### Random evidence and private saves

- `get_random_community_research_claim(locale, placement, random_cursor)` exposes only active,
  parent-approved/published, original-hash-valid content and resolves only a reviewed locale or
  safe fallback.
- The card renders the unmodified statement, publication, author(s), year and optional source
  link, plus an accessible red heart-plus save control.
- `set_community_research_claim_saved(claim_id, saved)` derives the user from `auth.uid()`.
  Saving requires currently publishable evidence; unsaving is always allowed for an existing own
  save, including after later withdrawal.
- `list_saved_community_research_claims(locale, limit, offset)` is authenticated-only, user-bound,
  locale-safe and clamped to 1–25 rows with a maximum offset of 10,000.
- Profile contains a compact saved-quote library with attribution, source links, pagination and
  optimistic removal/rollback.
- Query caches include the user identity. Save success invalidates only the matching user's
  library prefix; late responses from a prior identity cannot leak or refresh the new identity.

## Rollback

- Disable `circles` and/or `hub2` through the existing feature-flag/kill-switch path; do not
  delete Circle/Hub data to roll back availability.
- Withdraw or deactivate an incorrect claim. Preserve its source, review and save audit rows;
  users can still remove their private save.
- Revert the v1.12.0 frontend release commit to return presentation to v1.11.0 without touching
  unrelated event-feed or Connected City changes.
- Prefer a forward migration for schema correction. Do not drop evidence or save tables while
  audit/retention needs exist.
- If a locale is incorrect, set that translation to draft/pending review; do not alter the
  original Hungarian tuple to repair another language.
