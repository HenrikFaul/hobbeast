## What shipped

### Sprint 1.5 — Edge Function env-helper adoption
- `supabase/functions/shared/providerFetch.ts` now resolves the service role
  key via `requireEnv(['SUPABASE_SERVICE_ROLE_KEY'])`. Missing values fail
  with `MissingEnvError` and log the variable name only — never the value.
- `supabase/functions/sync-local-places/batchRunner.ts` replaces manual
  `Deno.env.get(...)` reads for `GEOAPIFY_API_KEY` and `TOMTOM_API_KEY`
  with the shared helper.

### Sprint 2 — Address Manager & Places
- Deleted duplicate `supabase/functions/address-manager-shared/`.
  Address-manager functions consistently import `_address-manager-shared/*`
  — the no-underscore copy was dead weight.
- Deleted duplicate `supabase/functions/sync-local-places/_shared/` tree.
  It carried an alternate `DEFAULT_SYNC_CONFIG` with
  `geo_limit: 60` / `tomtom_limit: 50` — the on-disk source of the
  "backend saved a smaller limit" ghost. No production code imported it.
- Only the active `sync-local-places/constants.ts` remains
  (`geo_limit: 6000`, `tomtom_limit: 6000`); clamp stays `1 .. 1_000_000`.
- Characterization test: `src/lib/__tests__/placeSearch.test.ts` locks the
  `NormalizedPlace` shape produced by `mapEdgePlace` (Geoapify + TomTom
  rows, sparse metadata fallback, rating→confidence clamp). `mapEdgePlace`
  is exported for testing.
