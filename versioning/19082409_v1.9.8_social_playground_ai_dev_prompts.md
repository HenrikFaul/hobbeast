## Product and design decision

Hobbeast remains the more capable product. The redesign therefore uses the reference set for
human photography, large editorial type, bright activity surfaces and clear social calls to
action, then connects those patterns to the application's existing route and state contracts.
No static imitation layer or reduced demo flow was introduced.

## Implemented expansion

1. Replace the home hero presentation with an original Budapest-riverside community visual,
   high-contrast editorial typography and real activity quick starts. Keep `/events` and
   `/about`, then add safe links to `/explore` and supported Events query parameters.
2. Present all six existing product capability families in a richer bento layout. Add a real
   homepage query handoff, personal/capacity/category discovery entry points and an auth-aware
   create-event action.
3. Add the existing Explore experience to the main navigation as `Hobbik`; retain its complete
   category → subcategory → activity state machine.
4. Recompose Events without touching its source/date/capacity/distance/personal/category query
   logic. Keep `q`, `source`, `mode`, `date`, `capacity`, `distance`, `km`, `cat`, `sub`,
   `activity`, `circle` and `create` URL contracts.
5. Upgrade event cards with validated HTTPS provider imagery, lazy loading, referrer isolation
   and emoji/gradient failure fallback. Preserve own/joined/interest/default states, promoted
   disclosure, open/join/leave/less-like-this callbacks and external-provider safety.
6. Recompose Auth and the shared shell without changing login, registration, OTP, resend,
   password recovery, OAuth, redirect sanitization, organizer, notification or profile logic.
7. Synchronize the vector mark and favicon, self-host the licensed display/body WOFF2 fonts,
   add reduced-motion behavior, AA small-copy contrast, visible dark-surface focus rings and
   explicit active-filter removal labels, and avoid nested interactive controls.
8. Protect the landing bundle by lazy-loading all below-fold sections. Keep the 20 KiB global
   CSS gzip ceiling; only the raw diagnostic ceiling changes to 116 KiB.

## Non-regression contracts

- Do not delete, rename or visually conceal existing product routes or role-aware controls.
- Do not change auth, organizer/admin authorization, privacy, exact-location or event lifecycle
  behavior as part of visual work.
- Do not fork the Events state model. New discovery entry points must serialize to the existing
  URL parameters and existing handlers must remain the only source of behavior.
- Preserve keyboard operation, accessible names, status/alert semantics, reduced-motion support
  and the exact `Promoted` disclosure.
- Keep external URLs behind `safeExternalUrl`; image enhancement must fail back locally.
- Use original or code-native assets. Do not ship competitor logos, screenshots or copy.
