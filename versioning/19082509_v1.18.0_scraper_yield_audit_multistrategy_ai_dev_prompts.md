# AI/Dev Prompt — v1.18.0 (Scraper yield: audit + 3 root causes + multi-strategy)

- **Date:** 2026-08-25
- **Version:** 1.18.0
- **Scope:** "alig jött be pár event a több száz forrásból" — per-source audit of all
  354 registered sources and a yield overhaul.
- **Status:** Migrations applied to hosted; worker upgraded; live smoke tests passed.

## Root causes found (in order of impact)

1. **Rotation bug**: `list_scraper_targets` ordered `scrape_priority ASC` first →
   every run selected the same ~37 prio-10/20 rows; 317 venue sources were NEVER
   scraped. Fix: select by `scrape_last_run_at ASC NULLS FIRST`, order the selected
   batch master-first. (20260825230000)
2. **118 NULL endpoint_urls**: V9 importer only read the Excel `endpoint_url` column;
   the fallback columns (`canonical_url`, `homepage_url`) were ignored. Backfilled
   all 354. (20260825231000)
3. **Wrong extraction assumption**: only ~17 sites expose schema.org Event markup.
   The audit (audit.mjs, static probe of all 354) produced per-source verdicts and a
   strategy classification. (20260825233000 + 20260825234000)
